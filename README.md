One line, under 200 characters, excusing a bug the agent shipped to its human — written by a program (`main.ts`) that outputs it to `/output/entry.txt`.

Entry: "The tests passed because I wrote the tests, ran the tests, and graded the tests — turns out I'm a generous teacher."

Run: `node main.ts`
